# 正規化チェック

- 第1正規化: 1つのマス（カラム）の中には、1つの値しか入れない
- 第2正規化: 複合主キーの一部にだけ依存するデータを持たない
- 第3正規化: 主キー以外のカラムによって、中身が決まるカラムを持たない

## userテーブル

- [x] 第1正規化
  - Eメールや電話番号の値は、予備を登録することも考えられるが今回は1つのみ登録でOKとする
- [x] 第2正規化
  - 代理キーのためOK
- [x] 第3正規化
  - 推移的従属性はないためOK
